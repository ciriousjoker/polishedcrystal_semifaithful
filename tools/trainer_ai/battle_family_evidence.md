# Shared family evidence packaging

`battle_family_evidence.py` serves only the bag and held-restorative collectors.
It copies hash-checked bytes into an empty output directory, indexes artifacts,
binds the existing executed manifest/ROM/SYM/generator/build receipt/log and
loaded Oracle/ABI identities, then emits the existing adapter and ledger schema.
Only missing required-rule failures are allowed before writing the ledger.
It neither executes fights nor imports native modules, drivers or observers.

Callers own explicit reviewed host pins and checkpoint formats, source fixture
and witness validation, terminal/replay/differential checks, rule selection and
control exclusion. Both retain the checkpoint before binding execution. A hash
of a current host or Oracle cannot replace missing execution-time provenance.
Initial runtime options remain checked from each actual retained initial WRAM
by the unchanged coverage gate. All original bytes remain unchanged, and a
merge only rebases derived artifact references.

There is no registration mechanism, generic witness language or family schema.
Move corpus observation and merge reference handling remain in their existing
tools. Gate, merger and actual runners are unchanged. Code preparation alone
proves no new coverage or equivalence; the external preparation task contains
the exact deferred comparison and negative-control commands.
